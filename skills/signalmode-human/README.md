# signalmode-human

Removes every detectable AI writing tell from output. Enforces a comprehensive banned-word, banned-phrase, banned-structure, and banned-punctuation ruleset.

## Usage

```
/signalmode-human     — Activate
/signalmode-human off — Deactivate
```

## What it removes

The skill enforces bans across six categories:

| Category | Examples removed |
|---|---|
| High-risk verbs | delve, leverage, utilize, harness, unlock, unleash, empower |
| High-risk adjectives | robust, seamless, holistic, cutting-edge, transformative, groundbreaking |
| High-risk nouns | ecosystem, synergy, paradigm, stakeholders, tapestry, roadmap |
| Banned openers | "In today's world", "When it comes to", "Now more than ever" |
| Helpful-bot phrases | "Sure!", "Certainly!", "Great question!", "I hope this helps" |
| Fake-suspense phrases | "Here's the thing", "But here's the truth", "Here's the kicker" |

It also bans em dashes (a primary AI tell), hedge-stacking, self-posed questions, lazy trailing clauses, and over-formatting patterns.

## What it produces

Output that reads like a sharp, experienced person wrote it. Confident. Practical. Calm. Slightly skeptical when needed. Comfortable making a direct call.

## Pair with

`/signalmode-voice` — adds verdict-first structure, tone calibration, and judgment standards on top of the vocabulary hygiene. Together they cover both dimensions of signal hygiene.
